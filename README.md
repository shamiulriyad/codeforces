## Overview

This repository holds my accepted solutions and drafts from Codeforces rounds. Each folder is one contest, so a solution sits next to the round it was written for.

- **Contests are grouped by division** (`Div (4)`, `div 3`, `div 2`, Educational, Global). Within a division, each round has its own folder and each problem is named by its index (`A.cpp`, `B.cpp`, …).
- **`Problem Solve/` is a flat practice set** of problems solved outside live contests. Files are named after the problem.
- **`sohoj coding contest/` holds topic drills**: graphs, number theory, string algorithms and recursion.

Grouping by division makes revision follow difficulty: start at Div. 4 to warm up, then move to Div. 3 and Div. 2 when you're ready for harder problems. Grouping by round keeps each problem set together, so you can re-solve a whole contest under time pressure.

## Problem-Solving Workflow

| Step | Focus | Key question |
|:-:|---|---|
| **1** | **Read the constraints** | What do *n* and the time limit allow: `O(n)`, `O(n log n)` or `O(n²)`? |
| **2** | **Find the pattern** | Is it greedy, math, sorting, two pointers, binary search, a graph or DP? |
| **3** | **Build the solution** | What is the simplest correct idea that fits the limits? |
| **4** | **Analyze complexity** | Have I checked time *and* memory before submitting? |
| **5** | **Test edge cases** | Does it handle `n = 1`, equal elements, the largest inputs and overflow? |
